# DDS Dental CR — SEO-first preview

This is a responsive static prototype, not the clinic's production website. The current preview is intentionally **noindex** and disallowed in robots.txt. Canonicals are placeholders pointing to the intended production domain; they must be reviewed at launch.

## Local preview
Run `python -m http.server 8000` from the project root.

## Launch checklist
- Approve clinical claims, branding, images, team credentials and contact details.
- Implement a secure, working contact workflow.
- Remove noindex and robots disallow only when the final domain and content are approved.
- Validate sitemap, canonicals, structured data, accessibility and Core Web Vitals.
- Add translated pages with reciprocal hreflang if bilingual content is approved.
